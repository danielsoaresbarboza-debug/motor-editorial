# Motor Editorial — fotos e postagem

Versão do Motor Editorial que roda fora do app do Claude, no navegador do celular.

- **Para que serve:** buscar as fotos dos slides automaticamente (fotos livres do Openverse, com crédito na legenda) e enviar o carrossel direto para o Instagram.
- **Como chega o carrossel:** no Motor dentro do Claude, toque em **Abrir para fotos e postar ↗**. O carrossel vem dentro do link.
- **Escrever e gerar carrosséis** (inclusive a partir de transcrições) continua no Motor dentro do Claude.
- **Ícone na tela inicial:** no Chrome, ⋮ → Adicionar à tela inicial.

Publicado pelo GitHub Pages (branch `main`, pasta raiz).
