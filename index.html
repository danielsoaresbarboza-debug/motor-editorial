Abrir no Motor vermelho ↗

Se o vermelho abriu sem o carrossel, toque em Colar do Motor azul lá. Se abriu dentro do Claude, use ⋮ → Abrir no Chrome.

Copia a legenda e manda todos os slides de uma vez. No Instagram, escolha Feed e cole a legenda.

Os slides com ponto vermelho ainda estão sem foto.

Posts de frase única

Duas imagens soltas do mesmo tema: uma frase em que a pessoa se reconhece e manda para alguém. Use **palavra** para destacar.

Fotos dos slides

Arraste a foto na prévia para mover. Use dois dedos (ou a roda do mouse) para o zoom.

Transcrições do Instagram

No Transcritor, toque em Levar ao Motor. As transcrições vão copiadas: cole aqui embaixo ou abra o arquivo .md.

A geração só funciona com o Motor aberto no Claude. Aqui dá para ler e copiar os temas.

Gerar a partir de uma ideia

Confira datas, nomes e números antes de postar. Fundamento que não aguenta uma busca não entra.

Colar JSON do chat

Formato do JSON 

          
**palavra** vira negrito. __palavra__ vira sublinhado (o destaque da capa). Tipos: capa, texto, imagem, foto, fecho. Fundo: escuro, claro ou cor.
